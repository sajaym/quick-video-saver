Quick Video Saver 2.0

Kisi bhi page ka video save karo: files, HLS/DASH streams aur 1000+ sites. Free. Local. No quota.

1 Install (sirf ek baar, 2 minute)

  1. ZIP par right-click → Extract All. Folder ko permanent jagah rakhein (jaise D:\Tools\Quick-Video-Saver).
  2. SETUP-WINDOWS.cmd par double-click karein. Admin access nahi chahiye. Full ZIP me sab tools included hain, internet nahi chahiye.
  3. Browser me chrome://extensions (Brave: brave://extensions, Edge: edge://extensions) kholein, Developer mode ON karein, Load unpacked dabayein aur package ka extension folder chunein.
  4. Browser restart karein, phir toolbar me puzzle icon → Quick Video Saver ko pin karein.
Pehle se install hai? Naya package usi folder me rakhein aur chrome://extensions me extension ke Reload (gol arrow) par click karein. Setup dobara nahi chalana.

2 Use

  1. Video wala page kholein aur video play karein.
  2. Toolbar icon dabayein (Alt+Shift+V). Card me page ka title, format, resolution, duration aur size dikhta hai.
  3. Quality chunein → Download. Progress usi card me dikhta hai; Downloads tab me sab jobs, speed aur ETA.
Video par Download buttonVideo par mouse le jayein ya play dabayein: top-right corner me Download button aata hai (IDM jaisa). Ek click = best quality; ▾ se quality ya Audio only. Band karne ke liye Settings → Button on videos, ya button ke menu me Hide on this site.
Side panelPopup me sidebar icon, ya Alt+Shift+S. Settings me icon ko hamesha side panel kholne par set kar sakte hain.
Analyze pageKuch na mile (hidden / blob video) to sparkle button dabayein. Helper page study karke stream dhoondta hai.

3 Kya kya apne aap sambhalta hai

  • Hidden streams: page ke andar fetch/XHR se aane wale m3u8/mpd (bina extension ke bhi) pakadta hai.
  • Protected links: Referer, cookies (login), browser identity aur custom headers same site ke liye replay karta hai.
  • Retry ladder: fail ho to Chrome-jaisi TLS identity → page extractor → FFmpeg direct copy.
  • Expire ho gaya link: page ne naya link bheja ho to khud retry; warna “Reload page” ka button.
  • Resume: adhura download wahin se; Live stream: Stop dabane par ab tak ki recording save.
  • Fake files: server ne error page diya ho to use video bata kar save nahi karta.

4 Problem?

“Helper not installed” dikh raha hai

SETUP-WINDOWS.cmd chalayein, browser poora band karke dobara kholein, phir extension me Settings → Helper → Check again. Folder move kiya ho to setup dobara chalayein.

Video detect nahi hua

Video play karke refresh icon dabayein. Phir sparkle (Analyze page). Extension install ke baad pehle se khule tabs ko reload kar lein.

403 / “link expired”

Page reload karke video play karein, phir download. Site me login zaroori ho to usi browser me login rakhein (Settings → Use my browser login ON).

“Unable to extract” / site achanak band

Settings → Update downloader. Zyadatar site-changes isi se theek ho jate hain.

“DRM protected”

Widevine/PlayReady/FairPlay se encrypted streams (Netflix, Prime, premium OTT) save nahi ho sakte. Ye technical limit hai.

Download folder badalna

Settings → Save to → Change…. Adhoori files us folder ke hidden .partial me rehti hain.

Hatana (uninstall)

Browser se extension remove karein, UNINSTALL-HELPER.cmd chalayein. Downloaded videos wahin rehte hain.
